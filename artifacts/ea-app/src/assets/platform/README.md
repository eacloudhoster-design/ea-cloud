# MetaTrader 5 artwork

`metatrader5.png` is the original full-colour MetaTrader 5 application icon, bundled locally for the platform heading. It is not generated, recoloured or redrawn. The original 512 × 512 PNG bytes and proportions are preserved. MetaTrader and its artwork are trademarks of MetaQuotes; use here identifies the supported platform and implies no endorsement.

The [manifest](manifest.json) records the SHA-256 and pinned public source from which the original app icon was retrieved on 21 October 2026. The official [MetaTrader 5 mobile page](https://www.metatrader5.com/en/mobile-trading) provides the platform reference. The download source is documented honestly as a public packaging mirror rather than a direct MetaQuotes download. No external image service is contacted at runtime.
