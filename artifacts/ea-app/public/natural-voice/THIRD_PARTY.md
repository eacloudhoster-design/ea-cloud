# Included voice/runtime materials

Kokoro v1.0 model and af_heart voice: https://huggingface.co/hexgrad/Kokoro-82M (Apache-2.0).
Int8 ONNX export: https://github.com/thewh1teagle/kokoro-onnx/releases/tag/model-files-v1.0 (kokoro-onnx wrapper MIT; model Apache-2.0).
Runtime: https://github.com/microsoft/onnxruntime/tree/v1.21.0 (MIT).
Phonemizer wrapper: https://github.com/xenova/phonemizer.js (Apache-2.0), package version 1.2.1.
Embedded eSpeak NG phoneme conversion: https://github.com/espeak-ng/espeak-ng (GPL-3.0). It supplies phonemes only; all audible audio is generated by Kokoro.

Retain the accompanying licence texts. Corresponding source/build instructions for the distributed phonemizer/eSpeak components are available from the upstream repositories and the versioned phonemizer npm source distribution; preserve GPL redistribution/source obligations. No endorsement by upstream authors is implied.

Model chunks, voice hashes and vocabulary are listed in model/manifest.json. The ONNX checkpoint is split without modification solely to respect the existing hosting platform's per-file limit. Generated common recordings use af_heart at speed 1.0, 24 kHz mono, peak-normalized to 0.85. No private account information is included.
